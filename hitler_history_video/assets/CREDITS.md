The narration voice is generated with Microsoft Edge neural TTS (`edge-tts`,
voice `en-GB-RyanNeural`). The page-flip, rubber-stamp, whoosh, bell, plane and
crowd-murmur sounds are synthesized in code.

**Music:** if `chopin.ogg` is missing (Wikimedia often rate-limits downloads),
the script synthesizes the main theme of Chopin's *Marche funèbre* (Piano Sonata
No. 2, 1839; the composition is public domain) as piano, in code.
**Drums:** if `drums.ogg` is missing, a snare march is synthesized.
